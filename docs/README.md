# Pusat Dokumentasi JogjaTrip

Dokumentasi ini disusun agar **pengguna**, **pengembang**, dan **penguji mata kuliah Interoperabilitas Lanjut** dapat menemukan informasi yang diperlukan tanpa harus membaca seluruh source code.

| Mulai dari | Dokumen | Pembahasan |
|---|---|---|
| Pengguna | [Panduan Pengguna](USER_GUIDE.md) | Memilih Hotel/Wisata, mengatur jam, menyusun perjalanan, memahami status |
| Pengembang / dosen | [Arsitektur](ARCHITECTURE.md) | Komponen sistem, hubungan data, domain authority, semantic interoperability |
| Integrator API | [API Reference](API_REFERENCE.md) | Endpoint, autentikasi, payload dan arti status |
| Kontributor | [Development Guide](DEVELOPMENT.md) | Struktur source, konfigurasi lokal, tes Go/Node, GitHub workflow |
| DevOps | [Cloudflare Deployment](DEPLOYMENT_CLOUDFLARE.md) | GitHub auto-deploy, D1, Workers, verifikasi |
| Reviewer | [Status & Batasan](PROJECT_STATUS.md) | Bukti tes vs status deployment, fitur ditunda, risiko |
